# Tests

## Test 1 - New customer signup, email OTP verification, and protected banking entry [sanity]
Viewport: mobile (375x667)
Covers: customer signup, Neon user persistence, email OTP delivery, five-minute OTP verification, protected banking interface
Description: Verifies a new tester can create a customer account and enter BH’S only after verifying the emailed code.
Steps:
1. Open BH’S while signed out and choose “Create an account”
2. Enter a full name, email, phone, password, and confirmation
3. Submit the signup form
4. Open the verification email and enter the six-digit OTP
5. Complete verification
Expected: The account is created, the OTP is accepted, and the BH’S banking interface opens showing the customer’s name.

## Test 2 - Returning customer login and sign out
Viewport: desktop (1280x800)
Covers: customer login, persistent session, logout, protected interface
Description: Verifies an existing verified customer can leave the banking interface and return with the same account.
Setup:
1. Complete Test 1 with a verified customer account
Steps:
1. Sign out from the More menu
2. Sign in with the same email and password
3. Open More
Expected: The customer returns to the banking interface with their saved name and can sign out again.

## Test 3 - Invalid or expired OTP is rejected
Viewport: mobile (375x667)
Covers: OTP validation, five-minute expiry guardrail, single-use verification
Description: Verifies invalid or expired verification codes cannot create an authenticated session.
Setup:
1. Start signup for a new email address and reach the OTP screen
Steps:
1. Enter an incorrect six-digit code
2. Observe the error
3. If the code expires, enter the expired code
Expected: Incorrect or expired codes do not create a session, and the user is instructed to request a new code.

## Test 4 - Signup validation blocks unsafe or incomplete credentials
Viewport: desktop (1280x800)
Covers: signup validation, password confirmation, required identity details
Description: Verifies incomplete or inconsistent signup details are rejected before authentication.
Steps:
1. Open Create an account
2. Submit with an invalid email or a password shorter than eight characters
3. Submit with mismatched password confirmation
Expected: Validation messages appear and no authenticated banking session is created.
